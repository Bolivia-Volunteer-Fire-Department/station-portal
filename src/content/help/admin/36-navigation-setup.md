# Navigation Setup

*System → Navigation Setup* configures the station's navigation layout, including the default landing screen, sidebar module ordering, custom module icons, and mobile navigation bar shortcuts.

IMAGE HERE

> [!IMPORTANT]
> Configuring navigation requires the **Manage system settings** permission.

## Default Landing Module

The **Default Module** card sets which screen members see immediately after signing in:

- **Dashboard (Default)** — Opens directly to the station timeclock and dashboard widgets.
- **Custom Landing Module** — Departments can choose any active module (such as Schedule or Tasks & Notes) as their default landing page based on operational priorities.

## Sidebar Navigation Order & Icons

The **Sidebar Navigation & Icons** card lets administrators customize the member sidebar:

IMAGE HERE

- **Reordering Modules** — Use the up and down arrow controls to adjust the order in which modules appear in the sidebar.
- **Custom Module Icons** — Click the edit button on any module to select a custom icon from over 80 emergency-services and organizational icons, organized across categories (Fire & Emergency, Time & Shifts, Personnel & Crew, Communication & Docs, Operations & System).
- **Reset to Defaults** — Restores the department's standard sidebar arrangement and default icons.

## Mobile Navigation Bar

IMAGE HERE

On smartphones and small mobile screens, StationSync renders a convenient bottom navigation bar:

- **Quick Shortcuts** — Select up to 5 primary modules to display as quick-access tabs along the bottom of mobile screens.
- **More Menu** — Any additional active modules remain easily accessible from the mobile slide-out menu drawer.
