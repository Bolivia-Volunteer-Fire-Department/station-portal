# Station Dashboard Layout Setup

*Administration → Content → Dashboard Setup* lets administrators design and arrange the default dashboard layout that all members see when signing into StationSync.

> [!IMPORTANT]
> Configuring the station default dashboard layout requires the **Manage dashboard setup** permission.

## Station Default Layout

The Dashboard serves as the command center for station operations and timekeeping. Administrators can organize widget cards across a flexible 3-column grid to ensure members immediately see the most relevant operational information:

- **Station Time & Duty Status**: Permanently locked in the top-left position and non-resizable. This guarantees members can always quickly punch in or out and check active shift time.
- **On Duty Personnel**: Displays members currently clocked into the station along with their active roles and ranks.
- **Announcements**: Highlights station notices, orders, and broadcasts targeted to the crew.
- **Upcoming Shifts**: Shows upcoming scheduled shifts and apparatus assignments.
- **Quick Action Links**: Rapid access to external department tools such as county CAD, weather radar, dispatch audio, and operating guidelines.

## Customizing the Default Layout

The visual grid editor provides intuitive tools to adjust your station layout:

1. Click **Add Widget** to insert enabled cards that are not currently in the layout.
2. Use the **Left** and **Right** arrow controls to reorder widgets across the grid placeholder system.
3. Use the **Expand** and **Contract** buttons to toggle widget widths between 1 Column, 2 Columns, or Full Width (3 Columns).
4. Remove non-essential widgets by clicking the **Remove (X)** button.
5. Click **Save Default Layout** to apply your changes station-wide.

> [!NOTE]
> Individual members can also personalize their personal dashboard view using the **Customize** button on the main Dashboard. If a member resets their view, it immediately reverts to this station default layout.
