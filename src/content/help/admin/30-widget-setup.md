# Dashboard Widgets Configuration

*Content → Widget Setup* enables administrators to manage built-in dashboard cards and create custom department widgets.

IMAGE HERE

> [!IMPORTANT]
> Managing dashboard widgets requires the **Manage dashboard widgets** permission.

## Managing Built-in Widgets

StationSync provides standard operational widgets that can be toggled on or off depending on station preferences:

IMAGE HERE

- **Station Time & Duty Status**: Core punch-clock and duty status card (always enabled).
- **On Duty Personnel**: Live roll-call card showing active duty personnel and apparatus assignments.
- **Station Announcements**: Notices and daily briefings targeted to members.
- **Upcoming Shifts**: Personal schedule countdown for signed-in members.
- **Quick Links**: Fast launch tiles for CAD systems, GIS maps, county dispatch audio, and operating guidelines.
- **Live Weather Radar**: Quick weather overview with one-click full-screen radar launch.

Use the toggle switch on any built-in widget card to enable or disable it. Disabled widgets are automatically hidden from member dashboards and the widget catalog.

## Creating Custom Department Widgets

Departments can create custom cards tailored to their unique needs:

1. Click **Create Custom Widget** in the top action bar.
2. Select a widget type:
   - **Rich Markdown / Notice Card**: Display shift pass-down logs, emergency phone directories, daily checklist reminders, or station policies with rich text formatting.
   - **External Web Embed / Quick Link**: Embed live webcams, CAD maps, county dispatch audio streams, or weather feeds.
3. Choose an icon, widget title, description, and default width (1 Column, 2 Columns, or Full Width).
4. Enter the markdown text or web embed URL.
5. Click **Create Widget** to add the new card to the station widget catalog.

> [!TIP]
> Custom widgets can be added directly to the station default layout in Dashboard Setup, making them instantly visible to all personnel across the department.
