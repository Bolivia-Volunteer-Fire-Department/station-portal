# Help Guide Screenshots & Diagrams

Place screenshots for Member and Administration Help Guides in:

- `public/help/member/` — referenced in markdown as `![Alt text](/help/member/filename.png "Optional caption")`
- `public/help/admin/` — referenced in markdown as `![Alt text](/help/admin/filename.png "Optional caption")`

### Optional Max-Width Sizing

Append `|<width>` to the alt text to constrain smaller UI crops or mobile screenshots:

```markdown
![Currently On Duty Widget|420](/help/member/on-duty-widget.png "Scheduled members clocked in are highlighted in green")
```
